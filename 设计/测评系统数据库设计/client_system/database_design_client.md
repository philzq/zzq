# 测评系统数据库设计文档

## 一、系统概述

**测评系统**是客户使用的系统，用于创建订单、填写订单、查询订单、管理店铺和产品、查看财务账单等。

## 二、数据库设计原则

1. 基于 eladmin 框架的数据库设计规范
2. 使用统一的字段命名规范（下划线命名）
3. 所有表包含创建时间、更新时间、创建人、更新人等基础字段
4. 支持逻辑删除（deleted 字段）
5. 客户只能查看和管理自己的数据

## 三、表结构设计

### 3.1 账号基本信息维护模块

#### 3.1.1 客户账号表 (client_customer)
- 存储客户账号基本信息
- 关联 eladmin 的 sys_user 表
- **客户权限**：查看和修改自己的账号信息

#### 3.1.2 客户子账户表 (client_customer_sub_account)
- 存储客户的子账户信息
- **客户管理员权限**：创建、编辑、禁用/启用子账户，分配权限

### 3.2 店铺管理模块

#### 3.2.1 店铺表 (client_store)
- 存储客户自己的店铺信息
- 关联平台
- 支持韩文名称和自定义备注名称
- **客户权限**：添加、修改自定义备注名称、删除店铺
- **业务逻辑**：删除店铺时，如果已有订单，则只标记删除，后台仍保留

### 3.3 产品管理模块

#### 3.3.1 产品表 (client_product)
- 存储客户自己的产品信息
- 支持自动添加（输入产品链接爬取）和手动添加
- **客户权限**：添加、修改、删除产品
- **业务逻辑**：已下单的产品信息不随产品修改而改变

#### 3.3.2 产品属性表 (client_product_attribute)
- 存储产品属性信息
- 支持多属性（以逗号分隔）

#### 3.3.3 产品图片表 (client_product_image)
- 存储产品图片信息
- 支持主图上传

### 3.4 订单创建和填写模块

#### 3.4.1 批次订单表 (client_order_batch)
- 存储客户创建的批次订单
- 支持点击、加购等批量订单创建
- **客户权限**：创建批次订单、查看自己的批次订单、取消未开始的订单

#### 3.4.2 明细订单表 (client_order_detail)
- 存储客户填写的明细订单
- 支持多种填写方式：
  - 某一天，单一产品的订单信息
  - 某一天，不同产品的订单信息
  - 某单一产品某几天的订单信息
  - 不同产品某几天的订单信息
- **客户权限**：填写订单、导入订单、重新提交订单、查看自己的明细订单

### 3.5 订单查询模块

#### 3.5.1 订单查询视图
- 待开始订单：提前填写，但还未到日期开始
- 进行中订单：当天订单，订单任务已经分配
- 待确认订单：还未上评的订单
- 已完成订单：订单已经评价完毕，订单终结（包含成交订单号、实际成交价格等返回信息）
- 批次订单：查看批次订单汇总
- 明细订单：查看明细订单详情

### 3.6 财务账单模块

#### 3.6.1 账单表 (client_bill)
- 存储客户自己的账单信息
- **客户权限**：查看自己的账单，支付佣金
- **业务逻辑**：提交订单时，根据订单类型支付佣金，显示预算金额，支付后显示实际付款

#### 3.6.2 账单明细表 (client_bill_detail)
- 存储账单明细信息
- **客户权限**：查看账单明细，每个明细订单也有对应的费用详情

### 3.7 使用帮助模块

#### 3.7.1 帮助文档表 (client_help_document)
- 存储帮助文档信息（从后台系统同步或独立维护）
- **客户权限**：查看帮助文档

## 四、关键业务逻辑

1. **账号创建**：客户账号由管理员创建，首次登录需短信/邮箱验证后设置密码
2. **子账户管理**：客户管理员可以创建子账户，并分配权限
3. **店铺管理**：
   - 添加店铺：输入店铺韩文名称+自定义备注名称
   - 修改店铺：仅支持修改自定义备注名称
   - 删除店铺：客户端删除，但如果已有订单，后台仍保留
4. **产品管理**：
   - 自动添加：输入产品链接，爬取产品信息自动添加
   - 手动添加：输入属性名称、产品主图、售价等
   - 修改产品：可以修改除产品ID外的所有信息
5. **订单创建**：
   - 创建批次：某一产品或某几个产品，未来某段时间内的点击/加购数量总数
   - 填写订单：支持多种填写方式，每个产品的关键词和测评订单类型可能不一样
   - 导入订单：可以选择任意已提交的订单重新提交
6. **订单查询**：
   - 按状态分类查询
   - 查看订单详情和返回信息
7. **财务账单**：
   - 提交订单时支付佣金
   - 显示预算金额和实际付款金额
   - 查看每个明细订单的费用详情

## 五、权限说明

### 客户管理员账号权限
- 查看所有客户订单数据
- 创建子账户
- 给子账户分配各项权限
- 管理店铺和产品
- 创建和填写订单
- 查看财务账单

### 客户子账户权限
- 根据客户管理员分配的权限进行操作
- 只能查看和管理分配的数据
