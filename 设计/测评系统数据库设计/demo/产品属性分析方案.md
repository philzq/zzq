
## 二、属性提取方案

### 方案1：从 PRODUCT_DETAIL_OPTION_LIST 提取（推荐）

**路径**: `quantityBase[0].moduleData[].items[]`

**提取逻辑**:
```java
// 1. 遍历 moduleData 数组
for (JsonNode module : moduleData) {
    String viewType = module.path("viewType").asText();
    
    // 2. 找到 PRODUCT_DETAIL_OPTION_LIST 模块
    if ("PRODUCT_DETAIL_OPTION_LIST".equals(viewType)) {
        JsonNode items = module.path("items");
        
        // 3. 遍历每个选项
        for (JsonNode item : items) {
            // 提取属性组合
            String itemName = item.path("itemBasicInfo")
                                 .path("itemName").asText();
            
            // 提取发货方式（从 deliveryUnificationBadgeArea.badge.badgeList[0].badgeId 读取）
            String deliveryType = "";
            JsonNode deliveryInfo = item.path("deliveryInfo");
            if (deliveryInfo.has("deliveryUnificationBadgeArea")) {
                JsonNode badgeArea = deliveryInfo.path("deliveryUnificationBadgeArea");
                JsonNode badge = badgeArea.path("badge");
                JsonNode badgeList = badge.path("badgeList");
                if (badgeList.isArray() && badgeList.size() > 0) {
                    deliveryType = badgeList.get(0).path("badgeId").asText();
                }
            }
            
            // 提取价格
            String finalPrice = item.path("priceInfo")
                                   .path("finalPrice").asText();
            
            // 提取vendorItemId
            Long vendorItemId = item.path("itemBasicInfo")
                                   .path("vendorItemId").asLong();
        }
    }
}
```

1. **ROCKET** (火箭配送)

### 2. 创建解析服务

```java
@Service
public class ProductAttributeParser {
    
    private final ObjectMapper objectMapper = new ObjectMapper();
    
    /**
     * 解析产品选项
     */
    public List<ProductOption> parseProductOptions(JsonNode rootNode) {
        List<ProductOption> options = new ArrayList<>();
        
        JsonNode moduleData = rootNode.path("quantityBase")
                                     .get(0)
                                     .path("moduleData");
        
        for (JsonNode module : moduleData) {
            if ("PRODUCT_DETAIL_OPTION_LIST".equals(
                    module.path("viewType").asText())) {
                
                JsonNode items = module.path("items");
                for (JsonNode item : items) {
                    ProductOption option = extractOption(item);
                    if (option != null) {
                        options.add(option);
                    }
                }
            }
        }
        
        return options;
    }
    
    /**
     * 根据发货方式筛选选项
     */
    public List<ProductOption> getOptionsByDeliveryType(
            List<ProductOption> options, String deliveryType) {
        return options.stream()
                     .filter(opt -> deliveryType.equals(opt.getDeliveryType()))
                     .collect(Collectors.toList());
    }
    
    /**
     * 根据vendorItemId获取发货方式
     */
    public String getDeliveryTypeByVendorItemId(
            List<ProductOption> options, Long vendorItemId) {
        return options.stream()
                     .filter(opt -> vendorItemId.equals(opt.getVendorItemId()))
                     .findFirst()
                     .map(ProductOption::getDeliveryType)
                     .orElse(null);
    }
    
    private ProductOption extractOption(JsonNode item) {
        ProductOption option = new ProductOption();
        
        JsonNode itemBasicInfo = item.path("itemBasicInfo");
        option.setItemName(itemBasicInfo.path("itemName").asText());
        option.setVendorItemId(itemBasicInfo.path("vendorItemId").asLong());
        option.setItemId(itemBasicInfo.path("itemId").asLong());
        
        JsonNode deliveryInfo = item.path("deliveryInfo");
        // 从 deliveryUnificationBadgeArea.badge.badgeList[0].badgeId 读取
        JsonNode badgeArea = deliveryInfo.path("deliveryUnificationBadgeArea");
        JsonNode badge = badgeArea.path("badge");
        JsonNode badgeList = badge.path("badgeList");
        if (badgeList.isArray() && badgeList.size() > 0) {
            option.setDeliveryType(badgeList.get(0).path("badgeId").asText());
        }
        
        JsonNode priceInfo = item.path("priceInfo");
        option.setFinalPrice(priceInfo.path("finalPrice").asText());
        
        return option;
    }
}
```

## 六、注意事项

1. **数据完整性**: 确保从 `PRODUCT_DETAIL_OPTION_LIST` 提取，这是最完整的数据源
2. **唯一标识**: 使用 `vendorItemId` 作为选项的唯一标识
3. **属性解析**: `itemName` 字段包含属性组合（如："레인보우 × 1세트"），需要解析出具体属性值
4. **发货方式变化**: 发货方式可能会根据库存、地区等因素变化，需要实时获取
5. **配送时效**: 可通过 `deliveryInfo.descriptions` 获取配送时效信息

## 七、扩展功能建议

4. **库存监控**: 监控各选项的库存状态（soldOut字段）
